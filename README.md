I'm a Thai developer in Bangkok. I build VTuber and streaming tools (live subtitles and translation for OBS) and backend services in TypeScript with Bun and Elysia. ## What I build

### VTuber Subtitle Studio

[vtuber-subtitle-studio](https://github.com/Lumichandesu/vtuber-subtitle-studio) shows live subtitles and Thai, Japanese and English translation in OBS, for VTubers and streamers. It is written in TypeScript and runs on Bun. The core is MIT-licensed. A Pro version is sold on [Gumroad](https://lumichandesu.gumroad.com/l/VTuber-Subtitle-Studio).

### Lumi Discord Bot

[lumi-discord-bot](https://github.com/Lumichandesu/lumi-discord-bot) is a self-hosted Discord music bot written in Rust (serenity and songbird) with a queue, loop, seek and lyrics.

### Yomumi

[Yomumi](https://www.yomumi.moe/) is a digital web novel and creative platform for stories, creators and community. I'm the founder. The platform's source code is private.

Two related public projects:

- [Yomumi Harness](https://github.com/Lumichandesu/yomumi-harness) compares Bun test runs and produces a compact report for human or AI review, without forwarding raw assertions or logs. MIT-licensed. The published example uses a controlled fixture, not a production benchmark.
- [Yomumi Status](https://github.com/Lumichandesu/yomumi-status) records independent public availability checks. It labels a browser challenge, an unexpected page, an outage and expired evidence separately.

## How I work

I like knowing how a system works from the network packet up to the application. On the backend I try to validate input, check access, handle failures carefully, and measure latency and resource use before tuning queries, caching or concurrency.
